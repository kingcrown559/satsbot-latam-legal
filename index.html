Política de privacidad

Última actualización: 18 de noviembre de 2026

Esta política explica qué información puede recibir y guardar SatsBot LATAM cuando una persona utiliza el bot de Telegram, para qué se utiliza y qué opciones tiene el usuario.

1. Información que recibimos

Cuando interactúas con SatsBot, Telegram nos proporciona datos técnicos y de cuenta necesarios para que el bot funcione, como tu identificador de usuario de Telegram y el contenido de los mensajes que envías.

Si eliges registrar un negocio, el bot guarda el nombre del negocio junto con tu identificador de Telegram. Las lecciones educativas pueden utilizarse sin registrar un negocio.

La versión actual de SatsBot no solicita claves privadas, frases de recuperación, contraseñas, datos bancarios ni credenciales de wallets. No procesa pagos ni mantiene saldos de Bitcoin.

2. Cómo usamos la información

Usamos la información para responder a tus mensajes, ofrecer las funciones del bot, guardar y mostrar el registro de negocio que solicites, mantener la seguridad y corregir errores.

3. Dónde se almacena

Los registros de negocio de la versión actual se guardan en una base de datos SQLite en el entorno donde se ejecuta el bot. El entorno de alojamiento puede procesar datos técnicos necesarios para operar el servicio. No incluyas información sensible en tus mensajes.

4. Compartición de información

No vendemos datos personales. Los mensajes se transmiten a través de Telegram y están sujetos también a las políticas y prácticas de Telegram. Los proveedores de infraestructura pueden procesar datos técnicos para alojar el bot. No compartimos deliberadamente los datos de registro con anunciantes.

5. Conservación y eliminación

Los datos de registro se conservan mientras permanezcan en la base de datos operativa o hasta que se eliminen durante tareas de mantenimiento. La versión actual no ofrece todavía un comando automático para borrar un registro. Puedes solicitar ayuda para revisar o eliminar tu registro escribiendo al bot y explicando tu solicitud; no envíes secretos ni datos financieros.

6. Seguridad

Tomamos medidas razonables para limitar el acceso a los datos y proteger las credenciales del bot. Ningún sistema conectado a Internet puede garantizar seguridad absoluta. Nunca compartas con SatsBot ni con nadie tu frase de recuperación o tus claves privadas.

7. Menores

SatsBot es un servicio educativo general y no está diseñado para recopilar deliberadamente información personal de menores. Si crees que un menor nos ha proporcionado datos personales, solicita su eliminación a través del bot.

8. Cambios a esta política

Podemos actualizar esta política cuando cambien las funciones o prácticas del servicio. Publicaremos la versión vigente en esta página e indicaremos la fecha de actualización.

9. Contacto y solicitudes de privacidad

Para preguntas o solicitudes relacionadas con privacidad, utiliza el chat de SatsBot LATAM en Telegram. Incluye una descripción de la solicitud, pero nunca incluyas contraseñas, claves privadas ni frases de recuperación.
